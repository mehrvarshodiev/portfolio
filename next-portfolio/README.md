# Mehrvar Shodiev — Premium Portfolio

A Next.js 15 App Router portfolio concept using TypeScript, Tailwind CSS 3.4, Framer Motion and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## Deploy

In Vercel, import this repository and set **Root Directory** to `next-portfolio`. The existing root project and GitHub Pages configuration are intentionally left untouched by this redesign branch.

## Notes

- Project preview panels are CSS-based visual placeholders; replace them with approved screenshots when available.
- Project links and social links should be checked before public launch.
- Experience milestones are intentionally generic and should be replaced with verified dates and achievements.
- The contact CTA opens Telegram. No backend contact form or email provider is configured.
- The project honors `prefers-reduced-motion` and includes responsive navigation and semantic landmarks.
